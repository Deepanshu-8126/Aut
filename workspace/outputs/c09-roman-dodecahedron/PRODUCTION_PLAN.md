## Script (locked spoken recording)
This Roman object has twelve sides, strange holes, and knobs on every corner. But what was it for? More than a hundred have been found across Europe, and their purpose is still a mystery. Some think it was a measuring tool. Others suggest knitting, or a ritual object. None of these ideas is proven. In 2023, archaeologists found one intact in England, giving them a rare chance to study where it was buried. So what do you think this Roman object was for?
