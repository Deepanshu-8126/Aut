## FORMAT LAWS (shorts)
1. **HOOK (0-2s):** scariest visual of the episode + one killer line. NO "ek baar ki baat hai". First frame = living poster.
2. **1 video = 1 part of 1 story.** Story split into 2-4 parts. Har part apne sabse tense moment pe CUT.
3. **CLIFFHANGER CUT:** black snap mid-action. Narrator stops MID-SENTENCE if possible.
4. **CTA (locked):** "...PART X me pata chalega. Subscribe kar lo — kahani abhi baaki hai." = genuine promise (next part ships within 24-48h).
5. **END CARD:** Question text + "PART X — KAL RAAT" + subscribe pill + SANNATA brand. On-screen text Hinglish/Latin only (no Devanagari fonts in renderer).
6. Length 30-40s. Painted-cartoon code engine (bhoottest2 kit). Viseme lip-sync only when character speaks on-screen; narrator lines = mouth closed.
7. Music/SFX: horror bed + heartbeat + riser into the cut. Honesty: .srt always.
