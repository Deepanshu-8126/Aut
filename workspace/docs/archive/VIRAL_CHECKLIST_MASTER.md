## ⚙️ ALGORITHM KI SACHAI (2025-26 — yeh samajh lo, baaki sab isi se nikla hai)
- Shorts mein **CTR matter nahi karta** — log click nahi karte, SWIPE karte hain. Dominant signal = **swipe-away rate + watch % (AVD)**.
- Seed test ≈ **200 viewers** → explore-and-exploit: signals achhe → pool badhta hai, kharab → push band.
- **March 2025 se har LOOP = alag view.** Seamless loop ab direct view-count + signal inflate karta hai. (Monetization ke liye alag "Engaged Views" metric hai.)
- Retention threshold: **<30s Short → ~65% AVD chahiye; 30-60s → ~50%.** Isliye sweet band 15-35s.
- Shorts **hafte baad bhi viral ho sakta hai** — re-discovery hota hai. 0-views pe delete NAHI (hamara law confirm hua).
- Algorithm padded/fake loop pakadne laga hai — loop GENUINE seamless hona chahiye, visual continuation.

## 📋 PHASE 1 — IDEA (video banane se PEHLE) 
**MrBeast rule: "Thumbnail kya? Title kya? First 5 sec kya? First 30 sec kya?" — yeh sab FILMING SE PEHLE decide.** (= hamara THUMBNAIL-FIRST + Topic Gate law)
- [ ] **Topic DNA check:** channel ke proven winners jaisa topic hai? (ROop_Loop = 2 named heroes + VS; Funcyous = mechanism; Chronic = dossier mystery). GRADER_LOG proof: topic DNA > polish.
- [ ] Title pehle likho, video baad mein. Title mein curiosity gap + keyword, answer LEAK nahi.
- [ ] **Loop pehle design karo, hook baad mein** — ending frame → opening frame ka visual handoff plan on paper.
- [ ] Simple premise: ek line mein bolo to samajh aa jaye? Nahi aata to idea reject.

## 📋 PHASE 2 — HOOK (0 se 3 second) — yahan video jeet-ta ya marta hai
- [ ] **Frame 1 = thumbnail hai.** Pehla frame hi bold, readable, punchy — text INSTANT visible (rl01 lesson: fade-in bhi mat rakho frame-0 pe).
- [ ] Pehle **1.5 sec mein macro visual change** (hamara hook law) — MrBeast: "video start nahi hoti, EXPLODE hoti hai."
- [ ] Hook mein poora premise clear: kya hoga + kyon dekhna hai. Zero intro, zero branding, zero "hello guys."
- [ ] **Jenga storytelling:** ending ki jhalak shuru mein de do jab possible ho (VS card = dono fighters + "WHO EATS MORE?" = yahi hai).
- [ ] Thumbnail/title ka promise first 5 sec mein deliver — bait-and-switch = retention death.

## 📋 PHASE 3 — BODY (retention engineering)
- [ ] **"Har second agle second ko earn kare"** — koi bhi moment jisme kuch naya nahi ho raha = CUT. (= NO STATIC HOLDS law, <1.5s frozen)
- [ ] **Hard visual event har ≤3 sec** (hamara core law; preflight check karta hai).
- [ ] **Crazy progression:** batao mat, DIKHAO — stakes har beat pe escalate (x1 burger → x10 → fire → GIANT cake).
- [ ] **Re-hook har 7-10 sec** (Shorts version of MrBeast's "3-minute re-engagement") — naya twist/round/reveal.
- [ ] Dead air ZERO — silence remove (hamara VOICE LAW), music bed continuous.
- [ ] Bold on-screen text taaki **sound-off viewer bhi follow kar sake** (YouTube text OCR bhi karta hai = topic signal).
- [ ] ⚠️ 2024 MrBeast correction: sirf fast cuts nahi — **STORY chahiye.** Cuts story serve karein, cuts-for-cuts nahi. (= hamara "flat edit REJECTED" + story-first law)

## 📋 PHASE 4 — ENDING + LOOP
- [ ] **ABRUPT ending** — MrBeast doc: payoff do aur KHATAM. Outro/"subscribe karo" ramble = log pehle hi bhaag jaate hain.
- [ ] **Seamless loop:** last frame → first frame visual continuation (same composition/palette/motion). Target seam diff <10 (rl01 = 3.1 ✅).
- [ ] Loop + curiosity: ending wahi sawaal re-ask kare jo opening answer karti hai ("REMATCH?" → "WHO EATS MORE?").
- [ ] Studio mein 100%+ retention spike second-1 pe = loop kaam kar raha hai.

## 📋 PHASE 5 — PACKAGING
- [ ] Title 40-70 ch, hook-first, keyword + hero/subject ka NAAM (12-views lesson: naam hataya = mara).
- [ ] Curiosity markers: ?, number, dash, trigger-word — kam se kam 2.
- [ ] Hashtags 3-5, #shorts included. >15 = sab void.
- [ ] Description: 1-line hook + keywords + (KM music ho to CC-BY credit MANDATORY).
- [ ] Pinned comment ready — **sawaal poochho** (comments = highest-weighted engagement signal).

## 📋 PHASE 6 — UPLOAD + AFTER
- [ ] Channel ke audience-active window mein upload (hamare slots: Funcyous/Chronic 7-9PM IST; ROop_Loop kids 5-7PM).
- [ ] Upload ke **pehle 2 ghante mein har comment ka reply** — early engagement velocity seed test ko boost karti hai (research: +15-20% reach).
- [ ] @72h tak NO judging, NO delete, NO re-upload. Actuals → GRADER_LOG.
- [ ] **MrBeast ka chhupa rule: "Pichhli video ka experience agli video ke views decide karta hai."** Har video best-effort — ek bhi lazy video channel ka trust girati hai.
